## Repository of the day

**[cactus-compute/needle](/repos/cactus-compute/needle)** — 14MB foundation model for tiny devices; phones, wearables, smart home, and robots.
Needle is a highly compact, 26-million parameter language model tailored specifically for structured function calling. Built on the Simple Attention Network architecture, it is designed for deployment in resource-constrained environments where standard large language models are impractical. It offers extremely fast inference, achieving 6000 tokens per second for prefilling and 1200 tokens per second for decoding when running on Cactus. The model can also be fine-tuned locally on consumer hardware like a standard Mac or PC. It is meticulously optimized for environments with minimal RAM, operating within a few hundred megabytes.

- Typical use cases: On-device tool execution; Edge computing automation; Custom function calling
