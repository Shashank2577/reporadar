## Repository of the day

**[NationalSecurityAgency/ghidra](/repos/NationalSecurityAgency/ghidra)** — Ghidra is a software reverse engineering (SRE) framework
Ghidra is a powerful software reverse engineering (SRE) platform designed to analyze compiled code across major platforms like Windows, macOS, and Linux. Created by the National Security Agency, it includes a suite of advanced tools for disassembly, assembly, decompilation, and control-flow graphing. The framework is highly extensible, allowing users to write custom scripts and plugins using Java or Python. It is widely used to dissect malicious code and uncover deep vulnerabilities within complex software systems. The tool scales well, making it ideal for large teams collaborating on extensive reverse engineering efforts.

- Typical use cases: Malware analysis; Vulnerability research; Automated decompilation
