## Repository of the day

**[Nutlope/hallmark](/repos/Nutlope/hallmark)** — Anti-AI-slop design skill for Claude Code, Cursor, and Codex.
Hallmark is a specialized Agent Skill tailored for Claude Code, designed to ensure that generated UI components feel organic and human-crafted. It achieves this by explicitly instructing the AI to avoid common generative hallmarks—such as generic Tailwind styling, symmetrical grid layouts, and overused color palettes. Instead, it guides the model to adopt asymmetric designs, distinct typography, and nuanced spacing that mirror professional, bespoke frontend development. The tool essentially acts as a stylistic governor, forcing the AI to produce frontend code that breaks away from the predictable 'AI look'. It integrates directly into the Claude Code workflow via the standard Agent Skills format.

- Typical use cases: Unique Landing Pages; Brand-Specific Prototyping; Component Library Expansion
