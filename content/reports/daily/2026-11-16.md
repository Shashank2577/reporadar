## Repository of the day

**[ag-ui-protocol/ag-ui](/repos/ag-ui-protocol/ag-ui)** — AG-UI: the Agent-User Interaction Protocol. Bring Agents into Frontend Applications.
AG-UI solves the lack of a common contract for streaming agent events to front‑end applications. It defines ~16 standard event types and a minimal set of inputs that agent backends can emit or accept. The protocol is transport‑agnostic, working over SSE, WebSockets, webhooks or any custom channel. A reference HTTP implementation and default connector let teams bootstrap an integration in minutes. Its middleware layer provides loose event format matching, enabling interoperability across diverse agent frameworks and UI stacks.
- Stars: 18,445 | Forks: 1,894 | Language: TypeScript | License: MIT
- Typical use cases: In‑app AI assistants; Customer support chatbots; Tool‑augmented IDE extensions
