## Repository of the day

**[pbakaus/impeccable](/repos/pbakaus/impeccable)** — The design language that makes your AI harness better at design.
Impeccable is a specialized design vocabulary and enforcement tool built to elevate the quality of frontend code generated by AI assistants. It specifically targets and eliminates common 'AI design tells'—like overused purple gradients, nested cards, and generic typography—by establishing a strict shared design context between the developer and the LLM. It initializes projects with explicit brand guidelines and provides 23 specialized commands (e.g., 'polish', 'quieter') to steer the AI's aesthetic choices. Crucially, it includes a suite of 60 deterministic, non-LLM detector rules that can instantly audit generated UI components for design flaws without requiring expensive API calls.

- Typical use cases: Guiding Brand-Specific Generation; Automated UI Auditing; Iterative Design Refinement
