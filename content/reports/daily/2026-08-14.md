## Repository of the day

**[anthropics/skills](/repos/anthropics/skills)** — Public repository for Agent Skills
This repository contains Anthropic's reference implementation for Agent Skills, which allows Claude to dynamically load instructions, scripts, and resources. These skills teach the AI model how to complete specific, repeatable tasks by extending its core capabilities with targeted knowledge and tool integrations. The project provides a standard framework for developers to create modular skills—such as adhering to brand guidelines or analyzing internal data structures—that Claude can seamlessly utilize. It is designed to bridge the gap between general AI capabilities and specialized, enterprise-grade workflows.
