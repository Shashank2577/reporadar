## Repository of the day

**[jingyaogong/minimind](/repos/jingyaogong/minimind)** — 🧠 两小时从 0 训出你的 64M 大模型。Train your own 64M LLM from scratch in 2 hours.
MiniMind provides a fully reproducible pipeline for building, pretraining, and fine-tuning a small-scale language model entirely from scratch in PyTorch. It drops heavy external frameworks in favor of native PyTorch code, implementing a custom 6,400-token BPE tokenizer to slash the memory overhead of the embedding and output layers. The repository walks users through the entire LLM lifecycle, from raw text ingestion to full-parameter instruction tuning on datasets like Alpaca. It proves that you can train a functioning, interactive chat model with less than 30 million parameters using just a single consumer GPU in a matter of hours.
