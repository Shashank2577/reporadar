## Repository of the day

**[JetBrains/thinkrail](/repos/JetBrains/thinkrail)** — Vibe code with pi in a lightweight, real IDE that customises itself around the way you work — The Vibe You Need
ThinkRail is an agentic IDE that builds a rich interface around the pi coding agent. It isolates work into separate git worktrees, enabling parallel agent tasks without disturbing the main checkout. It gives the agent durable project knowledge through living specifications (SPEC.md) and portable skills. It offers a splittable workbench with concurrent chat sessions, MCP server integrations, and inline tool previews.
