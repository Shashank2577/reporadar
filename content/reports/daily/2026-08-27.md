## Repository of the day

**[tt-a1i/archify](/repos/tt-a1i/archify)** — Agent skill for beautiful, verifiable architecture, workflow, sequence, data-flow, and lifecycle diagrams—self-contained HTML with motion and crisp export.
Archify serves as an advanced agent skill compatible with platforms like Cursor and Claude Code to dynamically map system architectures. It converts complex codebases and system descriptions into polished, interactive HTML diagrams without requiring manual charting. The tool supports multiple visual presets, precise Before/Delta/After snapshot comparisons, and exact tracing of upstream and downstream dependencies. By outputting fully self-contained HTML alongside SVG and PNG exports, it ensures diagrams are both trustworthy and easily shareable. This significantly accelerates the process of reviewing architectural changes and documenting complex systems.

- Typical use cases: Automated Architecture Documentation; Pre-merge Architecture Review; System Onboarding
