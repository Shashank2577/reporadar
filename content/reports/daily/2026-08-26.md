## Repository of the day

**[anthropics/claude-plugins-community](/repos/anthropics/claude-plugins-community)** — Community plugin marketplace for Claude Cowork and Claude Code. Read-only mirror — submit plugins at clau.de/plugin-directory-submission.
This repository hosts a curated collection of community-contributed plugins and skills for the Claude Code CLI and OpenClaw framework. It acts as a read-only mirror of the internal Anthropic review pipeline, syncing approved marketplace data nightly. By leveraging the Model Context Protocol (MCP), developers can install specialized tools to connect their local AI agents to external APIs, databases, and file systems. It provides a centralized hub to discover, install, and share custom capabilities that expand the core reasoning engine of Claude Code. All plugins distributed here have passed automated security scanning and official approval.

- Typical use cases: Local environment expansion; External API integration; Community collaboration
