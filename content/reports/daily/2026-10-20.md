## Repository of the day

**[stablyai/orca](/repos/stablyai/orca)** — Orca is the place for working with a fleet of agents (e.g. Grok Bot, Claude Code). Run any coding agent with your own subscription. Available on desktop, mobile and remote runtime.
Orca functions as a sophisticated Agent Development Environment (ADE) designed specifically to orchestrate fleets of parallel AI coding agents. It wraps multiple independent sessions, allowing users to concurrently run models like Claude Code, Codex, or Pi within their own isolated git worktrees. Available seamlessly across native desktop, mobile, and VPS environments, Orca centralizes task management and provides extremely fast, WebGL-rendered Ghostty-class terminals to monitor output. It effectively multiplies a single developer's bandwidth by allowing them to supervise and steer multiple autonomous refactoring or development tasks simultaneously.
