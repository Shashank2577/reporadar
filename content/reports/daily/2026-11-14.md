## Repository of the day

**[we-promise/sure](/repos/we-promise/sure)** — The personal finance app for everyone (by everyone)
Sure is an open-source personal finance and wealth management application that allows users to track cashflow, net worth, spending, and outflows. It is a community-maintained fork of the abandoned Maybe Finance project. The application can be self-hosted using Docker, providing users full control over their financial data. It is built with Ruby on Rails and PostgreSQL, featuring an optional AI assistant. It serves as a fully functional alternative to proprietary, subscription-based financial planning tools.

- Typical use cases: Track personal finances; Self-host financial data; Access financial insights with AI
