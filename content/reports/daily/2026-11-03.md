## Repository of the day

**[max-sixty/worktrunk](/repos/max-sixty/worktrunk)** — Worktrunk is a CLI for Git worktree management, designed for parallel AI agent workflows
Worktrunk is a command-line interface tool that radically simplifies the management of git worktrees. It reduces complex worktree commands down to three core actions, making them as intuitive as standard git branches. By automatically providing isolated directories, it enables users to run multiple AI coding agents like Claude Code or Codex simultaneously without encountering local file conflicts. The tool includes built-in hooks to automate local workflow setup across these parallel workspaces. Built in Rust, it ensures fast execution and seamless integration into existing developer environments.

- Typical use cases: Parallel AI coding; Context switching; Workspace automation
