## Repository of the day

**[meta/astryx](/repos/meta/astryx)** — An open source design system that's fully customizable and agent ready
Astryx is a massive open-source design system originating from Meta, engineered to be the foundational UI layer for both human developers and AI assistants. Built on top of React 19 and StyleX, it provides over 150 accessible, ready-to-use components alongside robust brand-level theming and native dark mode support. Unlike traditional design systems, Astryx features open internals that allow components to be composed at any level, and includes a swizzle CLI command to eject source code directly into a project. It explicitly aims to provide unified tooling that AI coding agents can understand and manipulate as effectively as human engineers.

- Typical use cases: Enterprise application scaling; AI-assisted UI development; Custom design system foundation
