## Repository of the day

**[vercel-labs/skills](/repos/vercel-labs/skills)** — The open agent skills tool - npx skills
This project provides a unified command-line interface for the open agent skills ecosystem, acting as a specialized package manager. It allows developers to easily install and utilize specialized capabilities across a wide array of popular AI coding agents, including OpenCode, Claude Code, Codex, and Cursor. The tool resolves sources from public GitHub repositories, private GitLab instances, or local file paths, and directly injects them into the agent's context. By establishing a standardized way to share, configure, and consume agent skills, it significantly enhances the practical utility and consistency of AI coding assistants across different development environments.

- Typical use cases: Agent capability extension; Cross-agent skill sharing; Private tool distribution
