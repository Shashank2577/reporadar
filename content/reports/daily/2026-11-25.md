## Repository of the day

**[XiaoYouChR/Ghost-Downloader-3](/repos/XiaoYouChR/Ghost-Downloader-3)** — The only downloader you need. 下载器的集大成者。
Ghost Downloader consolidates HTTP, BitTorrent, FTP, M3U8, MPEG‑DASH, eD2k, YouTube and Bilibili downloads into a single native application. It uses asyncio, uvloop and libtorrent to perform smart chunking that adapts to bandwidth without needing file merging. The app injects a browser extension to sniff media URLs, allowing seamless hand‑off from the browser to the desktop client. An aria2‑compatible RPC API lets external tools control tasks, and a plugin system (Feature Packs) enables extensibility. All components run on Windows, macOS, Linux and Android with a Fluent Design Qt UI.
