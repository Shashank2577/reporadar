## Repository of the day

**[ayghri/i-have-adhd](/repos/ayghri/i-have-adhd)** — A skill to stop your coding agent from burying the answer. ADHD-friendly output.
This repository provides a specialized skill plugin designed to modify the output of AI coding assistants like Claude Code to be more accessible for neurodivergent users. Instead of returning dense paragraphs or complex monolithic code blocks, the tool forces the AI to provide step-by-step, highly actionable outputs. It achieves this by injecting context-aware formatting prompts that suppress conversational boilerplate and prioritize task decomposition. By reducing cognitive load and decision paralysis, it creates a more structured and less overwhelming interaction loop for developers. It is completely localized for seamless installation directly into the AI tool.
- Stars: 28,023 | Forks: 1,756 | Language: Python | License: MIT
- Typical use cases: Overcoming decision paralysis; Step-by-step implementation; Reducing conversational noise
