## Repository of the day

**[Tracer-Cloud/opensre](/repos/Tracer-Cloud/opensre)** — The open-source agent for CI/CD reliability.
OpenSRE watches a CI run, extracts logs, commits, and correlated telemetry when a build turns red. It masks sensitive data then feeds the context to a locally hosted LLM to run a tool‑calling loop that formulates hypotheses and validates them against integrated services such as Datadog, Grafana, and GitLab. The agent distinguishes CI‑induced failures from code defects, produces an evidence‑linked answer, and optionally creates a remediation pull request. Results are posted back to Slack, PagerDuty, or Telegram, keeping the incident in the same workflow. All components run without external SaaS dependencies, allowing teams to keep models and data on‑premise.

- Typical use cases: CI Engineer on‑call; Automation pipeline; DevOps team with strict data policies
