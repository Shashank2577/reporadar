## Repository of the day

**[boykopovar/AnyPS5](/repos/boykopovar/AnyPS5)** — Tool for automatic PS5 executables porting to Linux and Windows
AnyPS5 provides automated porting of executables to Linux and Windows without relying on emulation or separate runtime processes. It achieves this by including a relinker that directly converts an executable into the target operating system's native format. Furthermore, it implements system prx libraries that are suitable for dynamic linking directly on the host system. This approach eliminates the performance overhead typically associated with emulation. The tool aims to progressively support more system functions over time.
- Stars: 12,904 | Forks: 984 | Language: C++ | License: GPL-2.0
- Typical use cases: Port games to PC; Analyze executable structures; Run console binaries natively
