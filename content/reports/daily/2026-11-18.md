## Repository of the day

**[cursor/plugins](/repos/cursor/plugins)** — Cursor plugin specification and official plugins
This repository serves as the official registry and codebase for plugins that extend the capabilities of the Cursor IDE and its internal AI agents. Each plugin is organized into its own standalone directory with a specific manifest, allowing users to integrate external services, documentation, and specialized workflows directly into their editor. The repository provides tools that give Cursor's agents direct access to resources like issue trackers, databases, and automated code review pipelines. It also includes scaffolding utilities so developers can rapidly build and validate their own custom plugins for proprietary internal systems.
