## Repository of the day

**[google-labs-code/stitch-skills](/repos/google-labs-code/stitch-skills)** — A library of Agent Skills designed to work with the Stitch MCP server. Each skill follows the Agent Skills open standard, for compatibility with coding agents such as Antigravity, Gemini CLI, Claude Code, Cursor.
The project addresses the lack of a unified, open-standard skill set for agents to interact with Google’s Stitch MCP design platform. It implements the Agent Skills specification in TypeScript, packaging each capability as a plugin with a SKILL.md manifest, scripts, resources, and examples. Skills cover design ingestion, generation, system management, and code export for React, React-Native, Vite dashboards, and video walkthroughs. By exposing these as Codex, Claude Code, Cursor, or OpenCode plugins, agents can invoke high-level UI operations without custom integration. The library’s sparse checkout support and modular plugin architecture make it lightweight and extensible.

- Typical use cases: UI Engineer automating design handoff; Product designer iterating rapid prototypes; Full-stack developer building cross‑platform apps
