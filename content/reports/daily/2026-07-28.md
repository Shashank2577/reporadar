## Repository of the day

**[amnezia-vpn/amnezia-client](/repos/amnezia-vpn/amnezia-client)** — Amnezia VPN Client (Desktop+Mobile)
Amnezia VPN Client allows users to deploy and manage their own VPN server directly on a remote server. It supports multiple VPN protocols including OpenVPN, WireGuard, and IKEv2, with additional traffic masking options like Shadowsocks and Cloak. The distinctive feature is its ability to automate server setup using Docker containers, simplifying self-hosted VPN deployment.
