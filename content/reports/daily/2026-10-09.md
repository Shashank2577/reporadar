## Repository of the day

**[anthropics/knowledge-work-plugins](/repos/anthropics/knowledge-work-plugins)** — Open source repository of plugins primarily intended for knowledge workers to use in Claude Cowork
This repository provides open-source plugins designed to transform Claude into a highly specialized assistant for various professional roles within a corporate environment. Built primarily for Claude Cowork but compatible with Claude Code, these plugins define specific workflows, data sources, and behavioral guidelines. They allow organizations to dictate exactly how Claude should approach tasks like financial analysis, HR screening, or project management. By exposing custom slash commands and integrating specific context, the plugins prevent the AI from falling back on generic responses. The project effectively bridges the gap between a generalized LLM and a specialized digital employee.

- Typical use cases: Financial Analysis; Human Resources; Project Management
