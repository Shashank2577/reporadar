## Repository of the day

**[Gitlawb/openclaude](/repos/Gitlawb/openclaude)** — runs anywhere. uses anything
OpenClaude is an advanced, terminal-based AI coding assistant designed to directly integrate with a developer's workspace and execute multi-step software tasks. It transcends simple chat by automatically parsing command-line parameters, reading local files, editing code, and executing terminal commands autonomously. The agent seamlessly supports multiple LLM providers, including Anthropic, OpenAI, and local models via Ollama, allowing developers to switch backends easily. Built completely in TypeScript, it features an interruptible execution loop, persistent conversational memory, and an interactive provider configuration flow to streamline authentication.
- Stars: 30,969 | Forks: 8,925 | Language: TypeScript | License: Other
- Typical use cases: Local Code Refactoring; Background Task Execution; Multi-Provider Prototyping
