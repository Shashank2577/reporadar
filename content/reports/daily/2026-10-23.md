## Repository of the day

**[fastapi/fastapi](/repos/fastapi/fastapi)** — FastAPI framework, high performance, easy to learn, fast to code, ready for production
FastAPI is a modern, high-performance web framework used for building APIs with Python. It leverages standard Python type hints to provide automatic validation, serialization, and interactive documentation. The framework is designed to be extremely fast, performing on par with Node.js and Go thanks to its underpinnings in Starlette and Pydantic. It significantly increases development speed by reducing boilerplate and providing excellent editor support with autocomplete everywhere. By standardizing around OpenAPI and JSON Schema, it ensures robust and production-ready endpoints.

- Typical use cases: Building Microservices; Creating Restful APIs; Serving Machine Learning Models
