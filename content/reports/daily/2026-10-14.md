## Repository of the day

**[xtool-org/xtool](/repos/xtool-org/xtool)** — Cross-platform Xcode replacement. Build and deploy iOS apps with SwiftPM on Linux, Windows, macOS.
xtool replicates core Xcode functionality using open standards across multiple operating systems. It enables building SwiftPM packages directly into iOS applications on Linux, WSL, and macOS environments. The tool also handles the signing and installation of iOS apps to physical devices or simulators. Furthermore, it allows programmatic interaction with Apple Developer Services for tasks like authentication and SDK management. By decoupling iOS development from Xcode and macOS, it provides a flexible toolchain for developers.

- Typical use cases: Develop iOS apps on Linux/Windows; Automate CI/CD pipelines; Programmatic Apple Developer interaction
