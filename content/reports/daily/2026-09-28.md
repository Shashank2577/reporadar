## Repository of the day

**[NawfalMotii79/PLFM_RADAR](/repos/NawfalMotii79/PLFM_RADAR)** — Open-source, low-cost 10.5 GHz PLFM phased array RADAR system
AERIS-10 democratizes advanced radar technology by providing open-source hardware and software for a 10.5 GHz phased array system. It utilizes Pulse Linear Frequency Modulation (PLFM), a technique normally reserved for sophisticated military or commercial aviation hardware, to achieve high-resolution target tracking. The project details two distinct hardware versions capable of 3km and 20km ranges, catering to different research needs. It provides full schematics, PCB layouts, and DSP (Digital Signal Processing) code, allowing enthusiasts to construct complex radar systems from accessible RF components. The software stack emphasizes integration with Software Defined Radios (SDR) for real-time signal analysis.
