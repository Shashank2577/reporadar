## Repository of the day

**[Alishahryar1/free-claude-code](/repos/Alishahryar1/free-claude-code)** — Use Claude Code, Codex, Pi, and OpenCode for free (1.3B+ free tokens) from your terminal, app, IDE, or phone like OpenClaw (voice supported + ToS friendly)
Free-Claude-Code functions as a transparent local proxy server that intercepts API requests natively dispatched by coding assistants (like Claude Code) and routes them to user-configured backends. It translates Anthropic-style tool calling syntax into standard OpenAI-compatible JSON payloads, allowing users to seamlessly swap the underlying model without modifying the client software. The proxy injects a custom catalog directly into the agent's model picker and implements local optimizations to save tokens, such as handling filepath extraction and quota probes on the machine rather than forwarding them to expensive APIs. This grants developers the flexibility to run complex coding tasks against free, locally hosted models or alternative cloud providers.
