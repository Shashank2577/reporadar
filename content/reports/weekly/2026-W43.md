## Repository of the week

**[cloudflare/security-audit-skill](/repos/cloudflare/security-audit-skill)** — A coding-agent skill for multi-phase security audits with independently verified, machine-readable findings
This project implements a specialized skill designed for AI coding agents to perform deep security auditing on codebases. Built on the Model Context Protocol (MCP), it exposes complex security analysis tools as a clean, standardized interface that LLM-powered agents can easily invoke. It integrates tools for static analysis, dependency vulnerability scanning, and secret detection. Rather than acting as a standalone CI/CD scanner, it is designed to be used interactively by an agent to investigate potential vulnerabilities during the development process. It allows an AI assistant to autonomously scan files, interpret the results, and subsequently propose or apply security patches.
- Stars: 46,568 | Forks: 2,893 | Language: JavaScript | License: MIT
- Typical use cases: Interactive security review; Automated patching; Dependency upgrading
