## Repository of the week

**[cursor/plugins](/repos/cursor/plugins)** — Cursor plugin specification and official plugins
This repository provides the official schemas and core registry for plugins designed for the Cursor IDE. It enables developers to extend Cursor's AI capabilities by connecting agents to external APIs, CI/CD pipelines, and internal company tools using the Model Context Protocol (MCP). The repo includes standard manifests and scaffolding utilities to help users build custom workflows, such as rigorous code reviews or specialized document rendering. By centralizing these plugins, it ensures that Cursor's AI models have reliable, structured access to the context they need to perform complex engineering tasks.
