## Repository of the week

**[anthropics/financial-services](/repos/anthropics/financial-services)** — 
This repository provides a comprehensive suite of reference agents, skills, and data connectors tailored for integrating Anthropic's Claude models into core financial services workflows. It targets specific use cases like investment banking, equity research, private equity, and wealth management. The project offers flexible deployment options, allowing the tools to be used either as a Claude Cowork plugin or deployed via the Claude Managed Agents API behind a custom workflow engine. It acts as a powerful starting point for institutions to safely and effectively automate the drafting of complex financial models, memos, and research notes.
- Stars: 37,848 | Forks: 5,465 | Language: Python | License: Apache-2.0
- Typical use cases: Automated equity research drafting; Investment banking memo generation; Wealth management portfolio summaries
