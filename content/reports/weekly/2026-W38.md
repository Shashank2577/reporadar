## Repository of the week

**[alibaba/open-code-review](/repos/alibaba/open-code-review)** — Secure, fast, efficient, battle-tested at Alibaba's scale. Hybrid architecture code review tool: deterministic pipelines + LLM Agent, precise line-level comments, built-in multi-language ruleset (NPE, thread-safety, XSS, SQL injection), OpenAI & Anthropic compatible.
OpenCodeReview automates pull request reviews by combining fast, deterministic static analysis with an advanced LLM agent. Developed and battle-tested at Alibaba, it seamlessly integrates into standard CI/CD pipelines. The tool scans for common logic errors like null pointer exceptions and thread safety issues, alongside security vulnerabilities like XSS and SQL injection. It utilizes language-specific rulesets to provide highly precise, line-level feedback directly within code hosting platforms. By enforcing coding standards and catching complex logic bugs early, it significantly accelerates the review cycle and reduces manual engineering effort.

- Typical use cases: Automated security scanning; Code quality enforcement; Accelerated PR reviews
