## Repository of the week

**[freestylefly/awesome-gpt-image-2](/repos/freestylefly/awesome-gpt-image-2)** — Prompt as Code | GPT-Image2 工业级提示词引擎与模板库，530+ 个案例逆向工程，20+ 套工业级模板，并提炼出Skills，持续更新中
The awesome-gpt-image-2 repository provides an extensive, curated collection of prompts, detailed workflows, and robust templates designed specifically for generating high-quality images with GPT-Image2. It meticulously includes over 500 reverse-engineered use cases alongside 20 highly structured industrial templates to significantly streamline the image generation process. The core philosophy of the project treats prompts as code, enabling fully reproducible and consistent visual outputs across various professional scenarios. Furthermore, the repository is complemented by a visual website that allows users to easily browse the extensive prompt gallery and filter by specific artistic styles or practical applications.
