## Repository of the month

**[omacom/omarchy](/repos/omacom/omarchy)** — Beautiful, Modern & Opinionated Linux
Omarchy acts as an opinionated wrapper around standard Linux distributions, heavily customizing the desktop environment, terminal, and core utilities out of the box. Designed by DHH, it aims to provide a beautiful, cohesive, and highly productive setup without requiring users to manually configure dotfiles or window managers. It bundles specific GUI themes, a unified clipboard system, specialized shell functions, and a curated set of development tools (including Neovim). The project focuses on creating a premium out-of-the-box experience specifically optimized for professional software development.
- Stars: 36,754 | Forks: 3,822 | Language: Shell | License: MIT
- Typical use cases: Developer workstation setup; Consistent environments; Transitioning to Linux
